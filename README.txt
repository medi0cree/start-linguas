START LINGUAS — сайт онлайн-школы языков
=========================================

Как выложить на сервер
----------------------
Скопируйте ВСЁ содержимое этой папки в корень сайта на сервере
(туда, где должен лежать index.html). Структуру папок не меняйте.
Сайт полностью автономный: шрифты, анимации и иконки лежат внутри,
интернет-библиотеки не нужны.

Чтобы открыть локально, достаточно дважды кликнуть index.html.

Структура
---------
index.html                  главная страница
favicon.ico                 иконка вкладки (для старых браузеров)
site.webmanifest            иконки для Android / «Добавить на экран»
robots.txt                  разрешение для поисковиков

assets/css/style.css        стили сайта (цвета в начале файла, блок :root)
assets/css/fonts.css        подключение шрифтов
assets/js/app.js            логика: каталог курсов, фильтры, подбор курса,
                            глобус, анимации. Курсы и цены — массив COURSES
                            в начале файла
assets/vendor/              библиотеки анимации: GSAP 3.12.5, ScrollTrigger,
                            Lenis 1.1.13 (плавная прокрутка)
assets/fonts/               шрифты Unbounded, Onest, JetBrains Mono, Caveat
                            (кириллица + латиница, лицензия SIL OFL)
assets/icons/               favicon.svg, apple-touch-icon, иконки 192/512
assets/img/og-image.png     превью ссылки для Telegram/WhatsApp/VK

Что стоит сделать после загрузки
--------------------------------
1. В index.html замените
     <meta property="og:image" content="assets/img/og-image.png">
   на полный адрес, например
     <meta property="og:image" content="https://ваш-домен.ru/assets/img/og-image.png">
   иначе часть мессенджеров не покажет картинку-превью.
2. Если браузер показывает старую иконку — обновите страницу с Ctrl+F5.

Как поменять цены или курсы
---------------------------
Откройте assets/js/app.js, найдите COURSES. У каждого курса есть
formats: solo (один на один), pair (в паре), group (в группе),
в них lesson — цена занятия, month — цена месяца, min — длительность.
